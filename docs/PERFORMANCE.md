# Performance methodology

These measurements are local, deterministic, synthetic benchmarks. They are not
exchange-feed capacity, co-located latency, or production SLO claims.

## Environment

- Host: Apple M3, arm64
- OS: Darwin 25.2.0
- Compiler: AppleClang 17 (`/usr/bin/c++`)
- Build: CMake Release, C++20
- Date: 2026-07-24

## Parser and replay

The input was generated by `scripts/generate_benchmark_fixture.py --pairs
500000`. It contains 1,000,001 framed messages, occupies 29,500,041 bytes, and
has SHA-256
`0602062f97338c5947167a7d78620d9bd04adfe3239be58954dcf1e5344f9a1f`.

Three fresh process runs produced:

| 1 | 103,222,583 | 9.688 | 143,161,875 | 6.985 |
| 2 | 96,955,584 | 10.314 | 143,073,916 | 6.989 |
| 3 | 97,279,125 | 10.280 | 141,309,666 | 7.077 |
| **Median** | **97,279,125** | **10.280** | **143,073,916** | **6.989** |

The parser timing includes file reading, framing, decoding, and event-vector
construction. Replay timing begins after parsing and includes per-instrument
book mutation and result calculation.

## Execution experiments

`execution-benchmark` evaluates TWAP, prior-session-profile VWAP, instrument POV,
and adaptive execution across six deterministic synthetic regimes: normal,
thin, high-volatility, wide-spread, front-loaded volume, and back-loaded volume.
Every parent finishes without invented liquidity. Adaptive saved **89.3276 bps
on average versus TWAP**, with **113.316 bps** population standard deviation.
The full per-strategy rows include completion, fill rate, shortfall, passive
ratio, fees, schedule deviation, and savings. The result is scenario-specific
simulation evidence, not an expected return.

## Risk

`risk-benchmark --iterations 1000000` ran one million approval checks with all
documented limits enabled and a reservation release after every approval. Audit
logging is disabled only for this microbenchmark. Approval latency excludes the
release; throughput includes approval plus release.

| Metric | Result |
|---|---:|
| p50 | 83 ns |
| p95 | 125 ns |
| p99 | 125 ns (0.125 μs) |
| maximum | 12,250 ns |
| end-to-end checks/second | 7.76036M |

Short isolated runs are sensitive to CPU frequency, caches, compiler, and OS
scheduling. Re-run on the target machine before using these numbers in any
capacity discussion.
