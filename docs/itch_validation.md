# ITCH decoder validation

The decoder uses one definition table with exact body sizes (type byte included): `S(12)`, `R(39)`, `H(25)`, `A(36)`, `F(40)`, `E(31)`, `C(36)`, `X(23)`, `D(19)`, `U(35)`, `P(44)`, `Q(40)`, and `B(19)`. It recognizes and safely skips `Y`, `L`, `V`, `W`, and `K` at documented lengths.

Known types with a wrong length and all truncated frames are errors. Unknown types fail in strict mode; permissive mode skips only the already-framed body and records the type and count. Parsed values retain stock locate, tracking number, timestamp, order IDs, match numbers, printability, prices, symbols, and MPID attribution where relevant.

This is independent fixture coverage, not a claim of official-feed validation.
